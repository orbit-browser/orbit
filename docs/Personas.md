# Orbit 페르소나

## 1. 다중 작업 지식 노동자

- 여러 조사와 업무를 동시에 진행한다.
- 프로젝트마다 관련 문서, 검색 결과, 협업 도구 탭을 많이 연다.
- 작업을 중단한 이유와 다음 행동을 빠르게 복구하고 싶다.
- 핵심 요구: 정확한 작업 단위 분류, 맥락 요약, 안정적인 복원

## 2. 리서치 중심 학습자

- 논문, 강의, 블로그, 문서를 비교하며 공부한다.
- 비슷한 제목의 자료가 많아 URL이나 제목 검색만으로는 부족하다.
- 핵심 요구: 목적 중심 자연어 검색, 핵심 정보와 미완료 항목 기록

## 3. 비교 탐색 사용자

- 여행, 쇼핑, 서비스 선택을 위해 여러 후보를 동시에 비교한다.
- 며칠 뒤 동일한 비교 작업으로 돌아오는 일이 많다.
- 핵심 요구: 후보 탭을 빠짐없이 보존하고 한 번에 다시 열기

## 4. 개인정보에 민감한 사용자

- 금융, 정부, 의료 페이지와 일반 조사 탭을 함께 사용한다.
- 페이지 본문이 외부 서비스로 전달되는지 중요하게 본다.
- 핵심 요구: 명확한 민감정보 제외 정책, 최소 권한, 실패를 숨기지 않는 상태 표시

## 공통 비목표 사용자

현재 MVP는 다음 요구를 우선 지원하지 않는다.

- 여러 사용자와 세션을 실시간 공동 편집하는 팀
- 브라우저 외부 문서를 중심으로 지식베이스를 구축하려는 사용자
- 완전한 북마크/히스토리 대체를 원하는 사용자
