# Orbit 완료 전 체크리스트

## 범위와 계획

- [ ] 사용자 요청과 완료 조건을 충족했다.
- [ ] `docs/Plan.md`와 실제 변경 범위가 일치한다.
- [ ] 요청하지 않은 리팩터링이나 기능 삭제가 없다.
- [ ] 기존 사용자 변경을 덮어쓰지 않았다.

## 계약과 데이터

- [ ] Backend 스키마와 Extension 타입이 일치한다.
- [ ] 외부 입력의 누락, 중복, 잘못된 형식을 검증한다.
- [ ] 저장 구조 변경에 마이그레이션 또는 절차가 있다.
- [ ] 비밀값과 환경별 값이 코드에 포함되지 않았다.

## 동작과 오류

- [ ] loading, empty, success, error 상태를 처리한다.
- [ ] 외부 AI/DB/검색 장애가 성공이나 빈 결과로 숨겨지지 않는다.
- [ ] 빈 AI 응답, 잘못된 JSON, 시간 초과를 처리한다.
- [ ] 사용자 오류 메시지에 스택이나 비밀정보가 없다.
- [ ] Chrome MV3 서비스 워커 재시작과 메시지 실패를 고려했다.

## 보안과 개인정보

- [ ] 필요한 Chrome 권한만 요청한다.
- [ ] 민감 페이지 본문 처리 정책을 지킨다.
- [ ] API 키, 토큰, 페이지 본문이 로그에 노출되지 않는다.
- [ ] 외부 배포라면 인증과 CORS 정책을 검토했다.

## 코드 품질

- [ ] 타입과 이름이 의도를 드러낸다.
- [ ] 사용하지 않는 코드, import, 임시 로그가 없다.
- [ ] UI, 도메인 로직, API, 데이터 계층의 경계를 지킨다.
- [ ] 새 의존성과 추상화가 실제 필요에 근거한다.

## 검증

- [ ] 관련 테스트를 실행했다.
- [ ] 실패 및 경계 조건 테스트가 있다.
- [ ] 가능한 전체 테스트를 실행했다.
- [ ] Extension 타입 검사/빌드를 실행했다.
- [ ] `git diff --check`를 통과했다.
- [ ] 실행하지 않은 검증과 이유를 기록했다.

## 문서와 전달

- [ ] 관련 README와 설계 문서를 갱신했다.
- [ ] 주요 결정을 `DecisionLog.md`에 기록했다.
- [ ] 작업과 검증을 `WorkLog.md`에 기록했다.
- [ ] 남은 위험과 TODO를 최종 보고에 포함했다.
