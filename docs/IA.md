# Orbit 정보 구조

## 1. Chrome Extension 사이드패널

### 전역 내비게이션

- 타임라인(신규 — 기본 진입 화면)
- 세션 목록(유지)
- 현재 탭/세션 저장 진입(유지)
- 자연어 검색
- 설정
- TopNavBar 세그먼트: 타임라인 / 세션 / Ask AI

### 타임라인 홈 (신규 — 기본 화면)

- `SyncStatusCard`: 오늘 방문 수, 미처리(미동기화) 이벤트 수, 마지막 동기화 시각, 수집 상태(활성/일시정지) 표시, "지금 저장"(수동 동기화) 버튼
- 날짜별 이벤트 스트림: 시각 역순으로 나열, 날짜 구분 헤더로 그룹화
- 이벤트 항목: 방문 시각, 파비콘(기존 컴포넌트 재사용), 제목, 도메인, 체류시간, 세션 배지(할당된 세션의 색/제목, 아직 배치 처리 전이면 "분류 대기")
- 미동기화 이벤트는 로컬 큐(IndexedDB)에서 직접 읽어 SW를 깨우지 않고 표시하며, 개별 삭제를 지원한다
- 세션 배지 클릭 시 세션 상세로 이동

### 현재 탭 및 저장 (유지)

- 현재 창의 탭 목록
- 탭 선택 상태
- 민감 도메인 본문 제외 설정
- AI 분류 및 저장 실행
- 분류/저장 진행 상태
- 성공 또는 실패 피드백

### 세션 목록 (유지)

- 세션 제목
- 상대 저장 시간
- 탭 수와 대표 탭
- 요약 처리 상태
- 세션 상세 진입
- 세션 복원, 이름 변경, 삭제

### 세션 상세

- 세션 제목
- 탐색 개요와 목적
- 핵심 정보
- 미완료 작업
- 다음 행동
- 포함된 탭 목록
- 전체 복원
- 요약 실패 시 재시도
- **탐색 타임라인(신규 섹션)**: 세션에 속한 방문 이벤트를 시간순으로 표시(시각/제목/도메인/체류시간/relevance) — 사용자가 "어떤 흐름으로 이 결론에 도달했는지" 확인할 수 있게 한다. 항목 클릭 시 해당 페이지를 연다. 백엔드 응답에 해당 필드가 있을 때만 표시되어 기존 화면과 독립적으로 배포 가능하다.

### 검색 (Intent 검색으로 확장)

- 자연어 검색 입력
- 리랭킹 설정
- 검색 결과: **세션 / 관련 기록 두 그룹(신규)** — 세션 카드(기존 컴포넌트) + 관련 방문 이벤트 행(타임라인 항목 컴포넌트 재사용)
- 검색 품질 저하 표시
- 빈 결과와 연결 오류 상태
- 결과 상세 및 복원

### 설정

- 민감 도메인 본문 제외 여부
- 검색 리랭킹 여부
- 백엔드 연결 상태
- **수집·동기화(신규 섹션)**: 수집 마스터 토글(기본 off, opt-in — 최초 활성화 시 안내 문구), 자동 동기화 on/off 및 주기(15/30/60분), 유휴 기준, 개수 기준, 본문 저장 토글, 민감 도메인 제외(기존 항목을 이 섹션으로 이동)

## 2. 웹 대시보드

### 홈

- 세션 목록/AI 검색 전환
- 검색 입력
- 최근 세션 카드
- 추천 작업 안내
- 로딩, 빈 상태, 오류 상태

### Analytics 섹션 (신규)

- 주제(세션)별 탐색 시간 top 5
- 자주 보는 사이트(도메인) top 5
- 반복 검색어·반복 방문 페이지
- 일별 탐색량(이벤트 수·체류시간) 추이
- CSS 막대 기반 시각화(차트 라이브러리 미도입 — 필요해지면 이후 결정)

### 세션 상세 패널

- 세션 요약 정보
- 탭별 링크
- 이름 변경과 삭제
- 요약 상태 및 재시도

## 3. Backend API 영역

- 세션 생성 및 클러스터 생성(유지 — "지금 열린 탭 스냅샷 저장" 경로로 존치)
- 세션 목록/상세/수정/삭제
- 요약 재시도
- 자연어 검색 및 선택적 리랭킹
- 상태 확인
- **이벤트 인제스트 및 동기화(신규)**: 배치 이벤트 수신, 미동기화 수 조회, 동기화 트리거, 동기화 상태 조회
- **세션 Timeline·버전 조회(신규)**
- **Intent 검색(scope=memory, 신규)**: 기본값(scope=sessions)은 기존 동작 그대로 유지
- **Exploration Analytics 집계(신규)**
- **이벤트 삭제(신규)**: 개인정보 통제 목적

## 4. 핵심 정보 관계

```text
브라우저 방문 이벤트
  -> (로컬 큐)
    -> Event Store
      -> 배치 AI 분석
        -> 세션
          -> 요약
          -> Timeline
          -> 검색 벡터
          -> 버전
```

기존 "탭 스냅샷 저장" 경로(`POST /sessions/cluster`)는 별도 진입점으로 유지되며, 이렇게 생성된 세션도 이벤트 기반 세션과 동일한 구조(요약/검색 벡터/버전)를 공유한다.

화면이나 API 흐름을 변경하면 이 문서와 `UserScenarios.md`를 함께 갱신한다.
