# Orbit 정보 구조

## 1. Chrome Extension 사이드패널

### 전역 내비게이션

- 현재 탭/세션 저장 진입
- 저장된 세션 목록
- 자연어 검색
- 설정

### 현재 탭 및 저장

- 현재 창의 탭 목록
- 탭 선택 상태
- 민감 도메인 본문 제외 설정
- AI 분류 및 저장 실행
- 분류/저장 진행 상태
- 성공 또는 실패 피드백

### 세션 목록

- 세션 제목
- 상대 저장 시간
- 탭 수와 대표 탭
- 요약 처리 상태
- 세션 상세 진입
- 세션 복원, 이름 변경, 삭제

### 세션 상세

- 세션 제목
- 탐색 개요와 목적
- 핵심 정보
- 미완료 작업
- 다음 행동
- 포함된 탭 목록
- 전체 복원
- 요약 실패 시 재시도

### 검색

- 자연어 검색 입력
- 리랭킹 설정
- 검색 결과와 검색 품질 저하 표시
- 빈 결과와 연결 오류 상태
- 결과 상세 및 복원

### 설정

- 민감 도메인 본문 제외 여부
- 검색 리랭킹 여부
- 백엔드 연결 상태

## 2. 웹 대시보드

### 홈

- 세션 목록/AI 검색 전환
- 검색 입력
- 최근 세션 카드
- 추천 작업 안내
- 로딩, 빈 상태, 오류 상태

### 세션 상세 패널

- 세션 요약 정보
- 탭별 링크
- 이름 변경과 삭제
- 요약 상태 및 재시도

## 3. Backend API 영역

- 세션 생성 및 클러스터 생성
- 세션 목록/상세/수정/삭제
- 요약 재시도
- 자연어 검색 및 선택적 리랭킹
- 상태 확인

## 4. 핵심 정보 관계

```text
브라우저 탭
  -> AI 클러스터
    -> 세션
      -> 요약
      -> 탭 목록
      -> 처리 상태
      -> 검색 벡터
```

화면이나 API 흐름을 변경하면 이 문서와 `UserScenarios.md`를 함께 갱신한다.
