# Orbit 사용자 시나리오

## 시나리오 1: 열린 탭을 작업 세션으로 저장

**전제:** 사용자가 Chrome에서 한 가지 이상의 작업을 수행하며 여러 탭을 열어두었다.

1. 사용자가 Orbit 사이드패널을 연다.
2. Orbit이 현재 창의 저장 가능한 탭을 보여준다.
3. 사용자가 저장을 실행한다.
4. Orbit이 탭을 작업 흐름별로 분류하고 임시 세션을 생성한다.
5. 백그라운드 요약이 완료되면 제목과 요약이 갱신된다.
6. 실패하면 실패 상태와 재시도 동작을 제공한다.

**완료 기준:** 선택한 모든 탭이 정확히 한 세션에 포함되고, 실패가 성공처럼 표시되지 않는다.

## 시나리오 2: 자연어로 과거 세션 검색

1. 사용자가 “지난주에 보던 일본 항공권 자료”처럼 목적 중심 검색어를 입력한다.
2. Backend가 검색어를 임베딩하고 관련 세션을 조회한다.
3. 설정에 따라 검색 결과를 리랭킹한다.
4. Extension이 관련 세션과 검색 상태를 표시한다.

**예외 흐름:** 검색 서비스 일부가 실패하면 품질 저하 상태를 표시한다. Backend 연결 자체가 실패하면 검색 결과 없음과 구분되는 오류를 보여준다.

## 시나리오 3: 세션 복원

1. 사용자가 세션 카드나 상세 화면에서 복원을 선택한다.
2. Orbit이 세션에 포함된 탭을 Chrome에 연다.
3. 일부 탭이 실패하면 성공한 탭과 실패한 탭 수를 구분해 알린다.

**완료 기준:** 실패한 탭 때문에 나머지 복원이 중단되지 않고 결과가 정확히 표시된다.

## 시나리오 4: AI 요약 재시도

1. 외부 AI 오류로 세션의 요약 상태가 `failed`가 된다.
2. 사용자가 재시도를 선택한다.
3. 상태가 `pending`으로 바뀌고 완료 여부를 폴링한다.
4. 성공하면 목록과 상세 화면이 모두 갱신된다.

## 시나리오 5: 민감 페이지가 포함된 세션 저장

1. 사용자가 금융, 정부, 의료 또는 로그인 페이지를 열어둔다.
2. 민감 도메인 제외 설정이 활성화되어 있다.
3. Orbit은 탭 제목과 URL은 복원을 위해 유지하되 본문과 발췌문은 전송하지 않는다.
4. 나머지 탭의 정보로 세션을 분류하고 요약한다.

## 시나리오 6: 빈 상태와 장애

- 저장된 세션이 없으면 Extension 설치 및 첫 저장 방법을 안내한다.
- 검색 결과가 없으면 쿼리와 일치하는 세션이 없음을 안내한다.
- Backend가 꺼져 있으면 서버 연결 오류를 안내한다.
- 외부 AI만 실패하면 저장된 임시 세션과 재시도 수단을 유지한다.
