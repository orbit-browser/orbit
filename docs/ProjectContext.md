# Orbit 프로젝트 컨텍스트

## 제품 개요

Orbit은 사용자가 열어둔 브라우저 탭을 AI가 작업 세션으로 분류·요약해 저장하고, 이후 자연어로 검색해 다시 열 수 있게 하는 Chrome Extension 중심 서비스다.

브라우저 탭을 단순 URL 목록이 아니라 사용자의 탐색 목적과 작업 흐름으로 취급한다. 핵심 경험은 “정리 없이 저장하고, 맥락으로 다시 찾고, 한 번에 복원하는 것”이다.

## 목표

- 열린 탭을 의미 있는 작업 세션으로 자동 분류한다.
- 세션의 목적, 핵심 내용, 미완료 작업과 다음 행동을 요약한다.
- 제목이나 URL이 아닌 자연어 맥락으로 과거 세션을 검색한다.
- 저장된 탭 묶음을 Chrome에서 복원한다.
- 민감한 페이지의 본문이 외부 AI 서비스로 전송되지 않도록 제한한다.

## 현재 구현 범위

- `extension/`: WXT, React, TypeScript 기반 Chrome MV3 사이드패널
- `backend/`: FastAPI, PostgreSQL, Qdrant 기반 세션 및 AI API
- `frontend/`: React, Vite 기반 세션 조회용 웹 대시보드
- LLM 탭 클러스터링, 요약, 임베딩 검색, 선택적 리랭킹
- 요약 및 임베딩 처리 상태 추적과 재시도 API

세부 구현 현황은 루트의 `README.md`와 `IMPLEMENTATION.md`를 참고한다. 알려진 결함과 개선 후보는 `docs/improvement-report.md`에 정리되어 있다.

## 주요 사용자 가치

1. 탭을 직접 분류하고 이름 붙이는 비용을 줄인다.
2. 시간이 지난 뒤에도 탭을 열었던 목적을 복구한다.
3. 여러 링크를 하나씩 찾지 않고 작업 단위로 복원한다.
4. 민감정보를 최소한으로 수집하면서 AI 기능을 제공한다.

## 제약

- Chrome MV3 서비스 워커는 유휴 상태에서 종료될 수 있다.
- 외부 AI API의 응답 지연, 호출 제한, 실패를 고려해야 한다.
- 브라우저 데이터와 페이지 본문은 개인정보가 될 수 있다.
- Extension, Backend, Frontend 사이의 API 타입과 상태 의미가 일치해야 한다.
- 로컬 데모 구성과 외부 배포 구성은 보안 요구가 다르다.
- 실제 API 키나 네트워크에 의존하지 않는 테스트가 필요하다.

## 현재 열린 제품 결정

- 세션을 큰 주제와 세부 작업 중 어느 단위로 나눌지
- 유사한 기존 세션에 새 탭을 병합할지와 사용자 확인 흐름
- 저장한 페이지 본문의 보관 기간과 재요약 지원 범위
- 웹 대시보드에서 세션 복원을 어디까지 지원할지
- 외부 배포 시 인증, 허용 origin, 운영 환경 구성을 어떻게 할지

해당 사항은 구현 전에 사용자 결정을 받고 `DecisionLog.md`에 기록한다.
