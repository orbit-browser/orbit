## 2026-07-05 — 탭 클러스터링에 LLM 유지

- 상태: 승인
- 배경: 짧은 제목과 URL, 수십 개 이하의 표본에서는 임베딩 기반 밀도 클러스터링의 품질과 안정성이 낮았다.
- 결정: Solar Mini 기반 프롬프트 클러스터링을 유지한다. 임베딩은 세션 검색에 사용한다.
- 대안: HDBSCAN과 cosine similarity 기반 클러스터링
- 근거와 영향: LLM이 그룹핑과 주제명 생성을 함께 수행할 수 있다. 외부 응답 실패와 잘못된 구조를 검증하고 fallback해야 한다.

## 2026-07-05 — 요약과 검색 모델 역할 분리

- 상태: 승인
- 배경: 작업 복잡도와 장애 특성이 서로 다르다.
- 결정: 요약은 A.X-K1을 우선 사용하고 Solar Pro 3를 fallback으로 사용한다. 경량 클러스터링과 리랭킹은 Solar Mini를 사용한다. 저장 벡터는 passage 모델, 검색어는 query 모델을 사용한다.
- 영향: 모델별 오류와 제한을 서비스 계층에서 구분해 처리해야 한다.

## 2026-07-05 — 민감 페이지는 본문만 제외

- 상태: 승인, 도메인 목록 보완 필요
- 배경: 개인정보 전송을 줄이면서 탭 복원 기능은 유지해야 한다.
- 결정: 민감 URL에 해당하면 제목과 URL은 유지하고 `text_content`와 `excerpt`는 비운다.
- 영향: 민감 도메인 판정의 정확성과 최소 권한 검토가 필요하다.

## 2026-07-12 — AI 요약 fallback과 실패 상태 분리

- 상태: 승인
- 배경: LLM 실패를 규칙 기반 요약으로 바꾸면 `summary_status=done`으로 기록되어 재시도와 장애 관측이 불가능했다.
- 결정: 규칙 기반 제목과 임시 요약은 최초 저장 응답에만 사용한다. AI 요약 오류와 빈 overview는 실패로 기록하고 임베딩하지 않는다.
- 영향: 기존 실패 재시도 API와 UI가 실제 외부 AI 실패 경로에서 동작한다.

## 2026-07-12 — 민감 도메인은 명시 목록으로 제한

- 상태: 승인
- 배경: `.or.kr` 전체 차단은 무관한 학회와 협회까지 제외했고 실제 국내 금융 도메인은 누락했다.
- 결정: 일반 `.or.kr` 차단을 제거하고 금융, 결제, 정부, 의료 도메인을 명시적으로 관리한다. 미사용 `bookmarks` 권한을 제거한다.
- 영향: 개인정보 보호 범위와 요약 품질의 균형이 개선되며 도메인 목록의 지속적인 검증이 필요하다.
