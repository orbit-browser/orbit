### 확인된 실패와 다음 조사

1. **세션 혼입/이름 변경:** 첫 배치의 ‘제주 여행 준비’ 3개가 두 번째 배치에서
   ‘DB 및 컨테이너 학습’ 8개로 바뀌었다. React 6개에는 Python 2개가 추가됐고,
   CSS Grid에는 Blender 2개가 추가됐다. 자동 병합은 꺼져 있다.
   배정/append와 요약 갱신 경로를 별도 버그 작업으로 조사해야 한다.
2. **검색 라우팅 오류:** `dev_shared`는 `/assistant/route`가
   `navigate_tab`, confidence 0.233781, margin 0.032449로 분류했다.
   대상 탭을 닫은 조건에서 저장 기록 대신 열린 탭을 찾다가 실패했다.
3. **답변/근거 모순:** `gpu_benchmark`의 Blender 카드와 부정 답변이 함께 표시됐다.
   원본 SSE와 화면을 보존했다.
4. **페이지 접근 차이:** 제주항공 403. 다른 제품의 200 응답과 같은 콘텐츠라고 주장할 수 없다.

이 실험에서는 위 문제를 수정하거나 질문을 바꿔 재측정하지 않았다.
합성 골든셋 100%와 이번 UI 결과를 하나의 정확도로 합치면 안 된다.
